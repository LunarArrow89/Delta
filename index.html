Language basics

Build a program with Delta. Press Ctrl + Enter to run it in a new window.

Show text

print("Hello, world!")

Save a value

let score = 10
print(score)

Do math

let total = 4 + 6 * 2
print(total)

Make a decision

let score = 12
if score >= 10 {
  print("You did it!")
} else {
  print("Try again")
}

Draw shapes in the program window

screen(640, 400)
background("#182033")
square(60, 80, 70, "#9c8cff")
circle(220, 120, 35, "#72e0b1")
text("Hello!", 60, 230, "#ffffff", 28)

Change a variable

let score = 1
score = score + 1
print(score)

Strings use quotes. Use // to write a comment. Statements can go on separate lines.
