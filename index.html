Language basics

Delta is a tiny game engine. Your running game opens as a screen with no extra interface. Press Ctrl + Enter to run.

Show centered text

text:Hello!:

Text between the colons appears in the middle of the screen.

Set the screen size

screen(640, 400)

Choose a background

background("#10131c")

Draw a square

square(60, 80, 70, "#9c8cff")

Draw a circle

circle(220, 120, 35, "#72e0b1")

Draw a rectangle

rect(40, 50, 120, 60, "#9c8cff")

Shape commands use x and y positions measured from the top-left corner. Use // to write a comment.
