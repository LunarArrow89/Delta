Language basics

Write a little code. Press Ctrl + Enter to run it.

Show text

print("Hello, world!")

Save a value

let score = 10
print(score)

Do math

let total = 4 + 6 * 2
print(total)

Make a decision

let score = 12
if score >= 10 {
  print("You did it!")
} else {
  print("Try again")
}

Change a variable

let score = 1
score = score + 1
print(score)

Strings use quotes. Use // to write a comment. Statements can go on separate lines.
